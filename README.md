# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Sales Performance Dashboard** developed in **Power BI** to analyze business sales data and uncover actionable insights. The dashboard enables stakeholders to monitor key performance metrics, identify sales trends, evaluate regional performance, and support data-driven decision-making.

---

## 🎯 Business Objectives

The dashboard was designed to answer the following business questions:

* How are overall sales and profits performing?
* Which regions generate the highest revenue?
* What are the top-performing product categories?
* How do sales trends vary over time?
* Which customers contribute the most revenue?
* What opportunities exist to improve business performance?
