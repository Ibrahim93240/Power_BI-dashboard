 Sales Dashboard Project
📌 Project Overview

This project is a Power BI Sales Dashboard created to analyze and visualize sales performance using interactive charts, KPIs, filters, and business insights.

The dashboard helps in understanding:

Total Sales Performance
Profit Analysis
Regional Performance
Category-wise Sales
Customer Trends
Monthly/Yearly Growth
Business Insights using Data Visualization
🛠️ Tools & Technologies Used
Power BI
Power Query
DAX
Excel / CSV Dataset
Data Cleaning & Transformation
